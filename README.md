# فلوسي — Floosy (Flutter Android MVP)

نسخة أولية تعمل دون Backend أو إنترنت. اللغة عربية وتصميم RTL. **المشروع مصدر Flutter وليس APK جاهزًا**.

## تشغيل التطبيق وإنشاء APK

1. نزّل Flutter SDK وثبّت Android Studio وAndroid SDK.
2. افتح Terminal في هذا المجلد، ونفّذ:

```bash
flutter create --platforms=android --project-name floosy .
flutter pub get
flutter run
```

3. لإنشاء APK قابل للتثبيت:

```bash
flutter build apk --release
```

ستجد الملف في `build/app/outputs/flutter-apk/app-release.apk`.

**تنبيه:** `flutter create` سيولّد مجلد `android/` المطلوب. لا تغيّر `lib/main.dart` ولا `pubspec.yaml`. إذا طُلب منك استبدال ملفات موجودة، احتفظ بالموجود.

## الموجود بالفعل
- شاشة تهيئة لتسجيل المرتب وحد البيت والأكل والتحويش والطوارئ والجمعيات والرصيد الافتتاحي.
- تسجيل المرتب مرة واحدة لكل دورة مالية 27–26، مع تخصيص أموال الادخار والطوارئ.
- تسجيل المصروفات وعرض سجل العمليات.
- ميزانية أكل بقيمة ابتدائية 4,000 جنيه قابلة للتعديل عند التهيئة.
- إنشاء أهداف شراء وحجز مبالغ من الرصيد المتاح لها.
- مساعد قرار شراء يعتمد على الرصيد بعد خصم المبالغ المحجوزة والتزامات الشهر.
- تخزين البيانات محليًا عبر `shared_preferences`.

## خارج نطاق النسخة الأولية الحالية
- لا توجد بصمة أو PIN أو تصدير ملف احتياطي؛ **لا تستخدمها لحفظ بيانات مهمة قبل إضافة النسخ الاحتياطي والحماية**.
- لا توجد حسابات نقدية متعددة أو تحويلات بينها.
- لا يوجد جدول تفصيلي لكل جمعية ولا إثبات قبضها.
- لا يوجد تسجيل تلقائي للفواتير أو إشعارات أو توقع نهاية الشهر أو تقارير تاريخية متقدمة.
- لا توجد خاصية تعديل/حذف العمليات أو تعديل الإعدادات بعد الإعداد الأول.
- قد ينتج عن إدخال أرصدة افتتاحية تشمل المرتب الجاري، ثم تسجيل المرتب نفسه، احتساب مزدوج. سجّل رصيدًا افتتاحيًا سابقًا للمرتب أو لا تضفه مجددًا.

## ملاحظات محاسبية
- رصيد التحويش والطوارئ هو تخصيص من المال الموجود، وليس مصروفًا إضافيًا.
- التكاليف الثابتة والميزانيات المحجوزة تقلل "المتاح الآمن"، ولا تقلل رصيد النقد إلا عند تسجيل المصروف فعليًا.
- إذا تجاوزت تخصيصات الادخار السيولة الموجودة، قد يصبح المتاح سالبًا. هذا تنبيه وليس سحبًا بنكيًا.
- التطبيق أولي للتجربة وليس مرجعًا محاسبيًا معتمدًا.
